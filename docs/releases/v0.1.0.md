# Omega VPN v0.1.0 — обновлённые пакеты

## Админка с входом и HTTPS

- Все страницы и API доступны только после входа администратора.
- Установщик создаёт случайные логин и пароль и выводит их в консоль вместе со ссылкой `https://<IP>:8443`.
- Пароль хранится как солёный PBKDF2-SHA256 хеш. В админке можно изменить логин и пароль, подтвердив текущий пароль.
- При изменении учётных данных завершаются все сессии. Есть выход, срок сессии 8 часов, защита CSRF и ограничение попыток входа.
- Для IP автоматически получается доверенный сертификат Let’s Encrypt с полной PEM-цепочкой; домен не требуется.
- IP-сертификат действует около шести дней; проверка продления запускается каждые четыре часа и после простоя. Админка загружает новые сертификаты без остановки VPN. Таймер и Certbot устанавливаются при быстром старте и деплое.
- Исправлен вход: запрос favicon и вторая вкладка больше не меняют защитный токен первой формы. При истечении токена показывается новая форма входа.
- При обновлении сохраняются пользователи, устройства и учётные данные администратора.

Установка или обновление от root на Debian 12+ / Ubuntu 22.04+ с systemd:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/develop-mdv/quantom_vpn/main/install.sh) v0.1.0
```

Разрешите 80/TCP, 443/UDP, 443/TCP и 8443/TCP в firewall хостинга. Если IP определяется неверно,
добавьте `OMEGA_PUBLIC_HOST=<IP_VPS>` перед командой установки.
Исходный пароль показывается один раз. При повторной установке используется существующий пароль.
Сброс забытого пароля: `cd /opt/omega && ./omega-server admin reset_web && systemctl restart omega-server`.

## Windows: один установочный файл

Скачайте `OmegaVPN-windows-x64-setup.exe` и запустите его. Клиент, Wintun и .NET runtime
встроены в EXE. Setup запрашивает UAC, распаковывает содержимое во временный каталог,
устанавливает или обновляет клиент, сохраняет профили и удаляет временные файлы.
Portable ZIP также доступен отдельно.

## Файлы

| Файл | Назначение |
| --- | --- |
| `OmegaVPN-windows-x64-setup.exe` | Автономный Windows x64 установщик одним файлом. |
| `OmegaVPN-windows-x64-portable.zip` | Portable Windows-клиент. |
| `OmegaVPN-android-debug.apk` | Тестовый Android APK для ARM64 и x86_64. |
| `omega-server-linux-x86_64.tar.gz` | Статический Linux-сервер x86_64. |
| `omega-server-linux-aarch64.tar.gz` | Статический Linux-сервер ARM64. |
| `SHA256SUMS` | SHA-256 пакетов. |

Android по-прежнему debug-сборка с тестовой подписью; при несовпадении подписи
старую тестовую версию потребуется удалить перед установкой. iOS-клиента нет.

При автодеплое первоначальные данные входа доступны root в `/opt/omega/state/admin-bootstrap.json`; пароль не попадает в логи Actions. Установщик выводит эти данные и удаляет файл, а смена пароля тоже удаляет его.
