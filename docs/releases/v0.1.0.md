# Omega VPN v0.1.0

Первый релиз с готовыми пакетами клиента и сервера.

| Файл | Назначение |
| --- | --- |
| `OmegaVPN-windows-x64-setup.zip` | Установка Windows-клиента x64. Распакуйте весь архив и запустите `Omega.Client.Setup.exe`. Папка `payload` должна оставаться рядом. |
| `OmegaVPN-windows-x64-portable.zip` | Portable Windows-клиент. Запустите `Omega.Client.App.exe` от администратора. |
| `OmegaVPN-android-debug.apk` | Тестовый Android-клиент для Android 6.0+, ARM64 и x86_64. Разрешите установку APK из выбранного источника. |
| `omega-server-linux-x86_64.tar.gz` | Linux-сервер для VPS x86_64. |
| `omega-server-linux-aarch64.tar.gz` | Linux-сервер для VPS ARM64. |
| `SHA256SUMS` | Контрольные суммы SHA-256 всех пакетов. |

Windows-пакеты содержат .NET runtime и Wintun; устанавливать Rust или .NET отдельно не требуется.
Профили установленного клиента сохраняются при обновлении.
Для подключения создайте пользователя и отдельное устройство в админке сервера, затем вставьте его код `omega://connect/...` в клиент.

## Быстрая установка сервера

На Debian 12+ / Ubuntu 22.04+ с systemd, от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/develop-mdv/quantom_vpn/v0.1.0/install.sh) v0.1.0
```

Скрипт скачивает готовый сервер, проверяет SHA-256, настраивает NAT и службу `omega-server`.
Файлы сервера: `/opt/omega`; настройки: `/etc/default/omega-server`.
VPN слушает UDP/TCP 443; IPv6 внутри туннеля по умолчанию отключён.
Перед созданием устройств добавьте в `/etc/default/omega-server`
`OMEGA_CLIENT_SERVER=203.0.113.1:443`, заменив `203.0.113.1` на публичный IP
или домен VPS, и выполните `systemctl restart omega-server`.
Иначе в кодах подключения останется placeholder `<SERVER_IP>`.
Админка доступна на `127.0.0.1:8081` через SSH-туннель:

```bash
ssh -N -L 8081:127.0.0.1:8081 root@<server_ip>
```

После этого откройте `http://127.0.0.1:8081` на своём ПК. У админки пока нет авторизации, поэтому новая установка не публикует её в интернет.

## Ограничения

- Android APK пока debug-сборка, подписанная тестовым ключом; для постоянных обновлений нужна release-подпись. При несовпадении подписи предыдущую тестовую сборку придётся удалить перед установкой.
- Клиента для iOS в проекте нет.
- Omega использует собственный протокол. Полный FEC datapath пока не завершён; подробности — в README.
